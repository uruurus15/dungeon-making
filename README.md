# Dungeon Making (1F・2F)

DS「ダンジョンメーカー 魔法のシャベルと小さな勇者」をお手本にした Rust 製の再現プロトタイプ。1F・2Fで「街 → ダンジョン → 街 → 家(食事・睡眠)」の1日サイクルが回る。

調査資料: `C:\Users\hamuh\research\dungeon-maker-shovel\`(map.md / log.md / sources/ / sources/img/ のスクリーンショット)

## 起動
- `play.cmd` をダブルクリック(ビルド済みの exe を起動)。ビルドは `cargo build --release`(WinLibs の `mingw64\bin` を PATH の先頭に)
- exe は自分の場所から `assets\` を探すので、どのフォルダから起動しても同じ素材・同じセーブを使う
- セーブは「ねる」ときに `savedata.json`(プロジェクト直下)へ自動保存。**更新前の古い版のセーブは読めません**(はじめからになります)

## テストプレイ(デバッグ)
- `debug.cmd` で起動(`--debug`)。通常起動にはデバッグ機能は一切ありません。セーブは別ファイル `savedata_debug.json`
- **F1** でパネル: おかね・アイテム追加・部屋ぜんぶ×5・シャベルMP全回復/上限99・オイル・全回復・むてき・ワンパン・夜をすごす・魔物を入れる・魔穴を今開く・隠しアイテム回収・クエスト全達成・階の移動・プリセット
- プリセット: 1F初日 / 1F今夜魔穴が開く直前 / 1F〜20Fの「開始」と「ボス直前」(手前の階は攻略ずみ)
- 上画面の「DEBUG (x,y) 評価」と、F1パネルの上半分に 座標・評価の内訳・ボス出現条件の進み具合 が出る

## 操作(左手でキーボード、右手でマウス/矢印)
| キー | はたらき |
|---|---|
| 矢印 / WASD | メニュー選択(←→は 個数や仲間の切りかえにも使う)。ダンジョン(3D表示)では W(↑)=すすむ(長押しで進みつづける)、A/S/D(←↓→)は ちょん押し=その向き(左・うしろ・右)を向く / 長押し=その向きへ 向いて すすむ。2D表示では 1回押すと向きが変わり、向いている方向と同じキーをもう一度押すと進む |
| Z / Space / Enter | 決定 / ダンジョンで あなを掘る・床をうめる(うめるは もう一度押す) |
| X / Backspace | キャンセル / ダンジョンで 部屋を置く・こわす |
| C / Esc | ダンジョンのメニュー(クエスト・もどす・町へかえる…) |
| V | まほう(リターン・ワープ・かいふく) |
| U | ひとつ もどす |
| Shift + 矢印 | (2D表示のみ) 向いている方向でも、動かずに向きだけ変える |
| Tab(または 上のバーの「2D/3Dにする」) | ダンジョンのマップを 3D と 2D で切りかえる(設定として保存される) |
| 戦闘中 Z を押しっぱなし | メッセージ早送り |
| F1 | (デバッグ起動のみ)デバッグパネル |

- 画面右下のボタンにも同じキーが書いてある。マップのとなりのマスをクリックすると向きを変え、もう一度で進む
- 戦闘の「おまかせ」: そのあとの行動をぜんぶ自動(回復→光→魔法→いちばん弱い敵を攻撃)。X か Esc で中止
- 食事の「おまかせ」、そうびの「さいきょう そうび」、町の「換金アイテムを全部売る」(毛皮・コインなど 売るための物だけ。装備・食材・クエストの品は売らない)、店の ←→ でまとめ買い/まとめ売り(x1/x5/x10)
- 「ダンジョンへ」は、行ったことのある階を選べる。ダンジョンのメニューの「町へ かえる」は どこからでも使える

## クエスト
- 街の「クエスト」ひとつにまとめた(受ける・届けるはここだけ。ダンジョンのメニューからは見るだけ)
- ★メインクエストが「いまの目標」。街のメッセージ欄・ダンジョン上のバー・朝の画面・ボードの先頭に1行で出る。メインは 12段階で、セーブには持たず いまの状態から計算する
- 村長の「いまの目標を きく」で 同じヒントが聞ける

## 戦闘・魔物の動き
- 通路の魔物は 入口から歩いて行ける床にだけ湧く(部屋でふさがれた穴には湧かず、いた魔物は夜に消える)。となりのマスに来ると 向かってきて戦闘になる
- 戦闘のメッセージは 決定キー/クリックで 1行ずつ進む(キーを押しっぱなしでは飛ばない。メニューの「戦闘ログ」で 自動に切りかえ可)
- 行動を選んでいるキャラの顔が メッセージ欄に出る。敵・味方を選ぶときは 左右キーでも選べる

## 会話シーンと立ち絵
- アレン・メイミ・ジェリーには **立ち絵**(`assets/img/stand_a/m/j.png`)がある。会話シーンと、店の人との話(村長・魔法屋など)で 背景の上に並び、しゃべっている人だけ明るく 少し弾み、名札が出る。描きかたは `src/stage.rs`、シーンの部品は `src/talk.rs`
- 台詞の行の頭: `アレン「…」`/`メイミ「…」`/`ジェリー「…」`=その人 / `＊`=地の文 / `※`=メイミがいるときだけ / 何も無い=その場の人(村長・店の人・手紙の差し出し人)。アレンは最初から場にいて、ほかの人は 最初にしゃべるときに 登場する
- 立ち絵の元は `art_work/raw/`(`char_hero`・`portrait_m`・`portrait_j`)の全身絵を マゼンタ抜きで切り出したもの。村長は 背景の絵(`scene_mayor`)に描かれているので 立ち絵は無い
- **はじめから**: 朝の自宅(アレンのひとりごと)→ 村長の家でシャベルを受けとる → **歩いて ダンジョン予定地へ**(背景が流れ、アレンと村長が はずむ)→ 予定地で「いい立地じゃろう」→ 村長の家(ヘビリンゴのうわさ・おびき寄せるダンジョン・魔法のシャベル・「今日からおぬしはダンジョンマスターじゃ!」)→ ダンジョンの入口に放り出される → 操作できる
- **あいさつまわり(はじめから1日目)**: アレンは **武器なし**で はじまる。ダンジョンから最初に町へ戻ると「みんなにあいさつしよう」の場面。武具屋・魔法屋・家具屋・広場・村長の家には赤い「!」が出て、行くと「ダンジョンマスター はじめました」のあいさつと その家の説明が聞ける。そのまま最初の依頼(武具屋=ワーネコのホルター、魔法屋=スライムのひもの、村長=カラスのももにく)も頼まれる。武具屋では 話のあと「かう」が開いてナイフに カーソルが合い、買うと そのまま そうびされる(戻らないで ダンジョンへ行くことも できる)。デバッグのプリセット・古いセーブでは しない
- **新入荷の話**: 家具屋は 新しい部屋が並ぶたび、魔法屋は 新しい品物・魔法(せいなる光・つよくなれ・すいみん・食材を見せて入荷する魔法)が並ぶたび、店の人が 話してくれる(一度だけ)
- **クエストの会話**: 達成すると 依頼者との会話の場面(背景は その人の家)のあと ほうびの内容が出る。受けて1日以上たつと、依頼者の家に行ったとき 一度だけ 催促・ヒントがある(サブクエストのみ)
- **ボスを倒したあと**: 次の朝に 村長の伝書バトが 手紙を届け、次のボスの「最近のうわさ」と「ダンジョンへおびき寄せて倒すこと」を知らせる(おびき寄せ方は 村長に会って聞く)。20Fのボスのあとは おしまいの手紙

## ダンジョンの 3D 表示
- 世界樹の迷宮のような、マス目の **一人称視点**。向いている方向を奥として、壁・床・天井・通路の魔物を 台形に描く(奥ほど暗い)。描画は `src/view3d.rs`
- カメラは なめらかに動く(進む・向きを変えるあいだも 描く)
- 部屋は **小部屋**として描く: とびら(木の枠)の奥に、しっくいの壁・木の巾木・床・天井があり、入口以外は 壁でふさがれている。中に 施設と魔物の **3Dモデル**が立つ(魔物は とびらの向きを向く)。3x3などの大きい部屋・4方向の部屋は 床いちめんに 絵が貼られ、中を歩ける(魔物は 立体)。入口が1つの3x3(どうじょう・じっけんしつ)も 中を歩けるが、出入りは入口からだけ(壁ごしには戦わない)。魔物は 他の部屋と同じく、上に乗るか となりに立つと 戦う
- **3Dモデル**(`src/model3d.rs`): 絵(`assets/img` の PNG)を 28×28(遠くは16×16)に区切り、ふちからの距離で ふくらませた 厚みを つけて、小さな立方体の 立体にしたもの。魔物も 施設も 同じ作り方(手でモデリングしたものではない)。通路の魔物も 立体で、こちらを向く
- **手で組んだモデル**(施設 全部): `src/modeling.rs`(部品: 面とり箱・まるい柱・回転体・たま・なだらかな山・草の葉・押し出し板・垂れ布・ほのお)、`src/facilities.rs`(1マスの施設)、`src/rooms3.rs`(3x3の施設)。頂点ごとに 向きと色を持つ なめらかな面で、色ムラ(れんが・板)つき。
  - 1マス: エサおけ・わらのベッド・ゴミすてば・てつ/ぎん/おうごんの たからばこ(ふた つき・あけた形つき)・さかば・さいだん・いろり・水のみば・りっぱなベッド・ごうかなベッド(天がい・カーテン)・だんろ・けっかいのへや・ふんすい・れいはいどう・れいぞうこ・まほうじん
  - 3x3: はたけ(うね・作物・かかし)・はなぞの・どうじょう・じっけんしつ・コロシアム(出入口4か所の かべ・かがり火)
- **魔物の手組みモデル**(全82種。`src/creatures.rs` `src/creatures2.rs`): 2頭身の 土台(頭・胴・うで・あし)に、耳・口もと・しっぽ・つの・ぼうし・よろい・マント・ぶき・たて・つばさを 組み合わせた「人型」(ワーネコ・ゴブリン・ウオリアー・ホネ・ワルキリーなど)と、スライム・おばけ・やさい/くだもの(ニンジン・ピーマン・ヘビリンゴ)・どうぶつ(コウモリ・バッファロー・ペンギン・カモノハシ・アナゲリラ)・アクトパス・エレファントム・ダルマ・サイコロ・まほうのたて・ドロヌマ・イモムシ・花 などの専用モデル。高さ1にそろえる。絵から作った立方体モデルは 使わなくなった(`model3d::build` は 予備)
- **モデル一覧**: **F4**(どの画面でも)で 開く/とじる。施設・魔物 全107体を 4×3 で ならべて ゆっくり回す。←→=1つずつ ↑↓=1行 Q・E=ページ Z=回転とめる V=えらんだ1体を大きく。`--screen models` / `--screen models_<ページ>` でも開ける
- 向いている先のマス(掘る・置く・埋めるの対象)は 水色の枠で 光る。目の前が部屋なら 部屋の名前も出る
- 下画面の ミニマップは そのまま(全体の地図)。2D表示に戻すと 今までの 見下ろしマップ
- 画面下の操作ヒントは 場面で変わる(3D / 2D / ふだん)。`ui.rs` の `TIP_*`
- 検証用: `--screen d3_<x>_<y>_<u|d|l|r>`(1Fの部屋つきの階で、その位置・向きの3D表示)

## パーティと物語の流れ
- **はじめから**は アレンひとり。**3日めの朝**に メイミが アレンの家に来て 仲間になる(場面あり)。**1Fのボス(ヘビリンゴ)をたおす**と、なついたスライムの **ジェリー**が仲間になる(場面あり)。まだ仲間でない人は 戦闘・ごはん・メニューに出ない。デバッグのプリセットは 最初から3人
- **魔法**(wiki「魔法」。値段が wiki に無い物は 設計値):
  - アレン: ひとりかいふく・ぜんいんかいふく・ひとりなおす・すいみん・つよくなれ(攻撃力+50%・戦闘中)・せいなる光・はねかえせ(魔法・特殊攻撃を1回ふせぐ。クエスト「かがみのころも」の報酬)
  - メイミ: もえあがれ・炎のあらし・氷のつぶて・ふぶき・ふういん・いのちぎりぎり(HPを1に。ボスには ききにくい)・いのちいただき(敵全員のHPを吸って仲間を回復。エレファントムは はねかえす)
  - 氷のつぶて・炎のあらし・ふぶき・ふういん・いのちぎりぎり・いのちいただき は、対応する食材(水ライム/火ライムのひもの・イワシ・ハマグリ・ドクライムのひもの・かわざかな)を 魔法屋に見せると入荷する
  - **ふういん**: ふういんされた敵は 特殊攻撃を使えず、ふういんされた味方は 魔法が使えない(数回の行動のあいだ)。ミツメオニの封印ビームとデビルロードのふういんのじゅつは本物の封印。「ひとりなおす」で なおる
- **部屋のとくせい**(wiki「家具」): けっかいのへや=魔物が ふういん状態ではじまる / まほうじん=魔物が とても強い(HP・守り1.5倍) / りっぱなベッド=寝ている / さかば=よっぱらい。でたらめなけん=ダメージが 0〜3倍で ばらばら
- **モノマネスライム(ジェリー)**: メニューの「ものまね」で、たおした魔物の あたま・うで・からだ・あしを マネする。
  - あたま=かしこさ・MP・兜・魔法(ワライオバケ→ふういん、ネコマタ→ひとりかいふく(7F以降は ぜんいんかいふく)、アツイオバケ→もえあがれ、サムイオバケ→氷のつぶて、など。一度おぼえたら わすれない)
  - うで=つよさ・武器・盾・指輪・特技(ちからまかせ・かいてんぎり・ひっさつけん…。攻撃のとき ときどき出る)
  - からだ=HP・じょうぶさ・鎧 / あし=すばやさ・靴
  - 能力の増え方は 魔物の強さから決めた設計値(wiki は階ごとの実測値)。ボスは マネできない。wiki の表にない11F以降の魔物の行は 設計値。「おまかせ」で いちばん強くなる組み合わせにできる

## 町の人の話(イベント)
- 家(武具屋・魔法屋・村長)に入ると、まだ頼まれていないクエストがあれば その人が頼みごとを話し、サブクエストは そこで「受けた」状態になる(前金があればもらう)。クエストボードには 頼まれたクエストだけが出る。メインクエストは 階に降りたときに受けた状態になり、村長が その話をする
- 家具屋は、新しい部屋が入荷していたら その説明をする(はじめて行ったときは 基本の部屋の説明)
- 村長の「いまの目標を きく」は、村長の言葉で 次の目標を伝える。話の途中は Z/クリックで 1行ずつ進む
- 話すことがある家には 町の地図に赤い「!」が出る

## 画面(スマホ縦 / PC横)
- 内部の画面は 576x864(DS の二画面を縦に並べた形)。窓の大きさ・形に合わせて 2通りに写す

## 宝箱と鍵
- 宝箱は 鉄(700G)・銀(4000G・6Fから)・金(おうごんチェスト 9000G・11Fから。wiki では18Fから)。入口の前に立ち、対応する鍵(てつのカギ/ぎんのカギ/おうごんのカギ)を持っていると自動で開く
- 中身は、鉄=その階、銀=1階ぶん深い階、金=2階ぶん深い階の宝箱の表から(アイテムだけ)。10Fの鉄の宝箱は食べ物だけなので、銀・金はその次の階の表を使う。20F より深い分は wiki B20F の銀(カオスバスター・カオスブリンガー・めがみのティアラ…)・金(めいおうのつえ・せいぎのよろい…)の表
- 鍵は魔物を倒したときに落ちる(鉄5%・銀2%=6Fから・金1%=11Fから。ボスは落とさない。店では売っていない)
- **フロアの魔物を狩りつくすと、中身のある宝箱の鍵がかならず出る**(その箱の鍵を持っていないときだけ)
- 開けた宝箱は、**鉄2日・銀4日・金7日(最大)で補充**される。ただし補充の日数が進むのは、その階に魔物が一定数いる夜だけ(鉄3匹・銀6匹・金9匹以上。金は18匹以上だと2倍の早さ)。魔物の数は設計値

## 1日の流れ
1. 町(1枚絵)で買い物・クエスト → 「ダンジョンへ」
2. シャベルMP(毎日全回復)で壁を掘り、部屋(家具)を置く。部屋の入口の前に立つと中の魔物が出てきて戦闘
3. 町で不用品を売る(武具屋=装備 / 魔法屋=薬・毛皮 / 家具屋=部屋 / 広場=食材)
4. 家で食事(ひとり1日1回・食べた人のステータスUP)→ ねる。夜のあいだに部屋へ魔物がすみつく

- 魔物の落とす **装備品に +1〜+(置いた数)** がつく。**+1ごとに 元の能力の6%アップ**(各段階 切り上げ。+5=30%)。耐性・特技などの特殊効果は そのまま。名前は「ナイフ+3」のように 別の品物として持てる(売ると 武具屋には +なしの品が並ぶ)
- 瘴気で 強くなった魔物を倒すと、ものまねの能力が **倒した最大の強さで上書き**される(「ショーグンウルフ+3」。+1ごとに 増え方が 1.2倍・切り上げ)
- 確認用: `--screen miasma<個数>`

- 村長の立ち絵(`stand_mayor`)と、歩く場面・ダンジョン予定地の背景(`scene_walk`・`scene_site`)を追加。はじめからの台詞は `script.rs` の `intro_mayor`(家)→`intro_walk`(道)→`intro_site`(予定地)→`intro_dungeon`。確認用: `--screen scene_intro3`(歩く)/`scene_intro4`(予定地)

- **寝る前の警告**: まだごはんを食べていない仲間がいるのに「ねる」を選ぶと、アレンが 名前入りで 「ちょっと待って。僕とジェリーは まだ ごはんを 食べてないよ。…」と 注意する(顔つき)
- **ジェリーのあいづち**: 仲間になったあと、村長の話・ボスの知らせ・クエスト達成の会話に「ジェリー「ぷるん!」」などが ところどころ入る(`script.rs`。仲間になる前は 自動で 消える)

## Web版(GitHub Pages)
- ビルド: `cargo build --release --target wasm32-unknown-unknown` → `python tools/pack_web.py`(`docs/` に index.html・wasm・JS・assets.pack(画像・音・フォントを1つに)ができる)
- 確認: `cd docs && python -m http.server 8765` → ブラウザで http://localhost:8765/ 。ヘッドレス確認は `python tools/web_probe.py`(コンソールログ・画面・フレーム時間)
- セーブ・設定は ブラウザの localStorage。素材は 初回に assets.pack(約14MB)を まとめて ダウンロード。日本語フォントは 同梱の Noto Sans JP(OFL・使う文字だけに 絞った 約0.5MB)
- タイトルで **F2** を押すと、12Fの 部屋と魔物が たくさんある ダンジョンが 3D表示で 開く(動作確認用)
- 公開: GitHub の Settings → Pages で `main` ブランチの `/docs` を 公開元にする

- **タイトルへ もどる**: メニュー(C)の「タイトルへ もどる」。「寝ていない データは セーブされません。」と警告して 確認する(セーブは 家で寝たとき)
- **階段・魔穴の3Dモデル**(`facilities.rs` の `stairs_up`/`stairs_down`/`portal_hole`)。自分が 乗っている マスでは 描かない
- **設備を 背にしても 視界が つぶれない**: 目の うしろ・すぐそばの モデルは 描かない(`model3d::draw_model`)

- **ボスのものまね**: まほうじんで 出た ボスを 倒したときだけ 覚える(本物の ボス戦では 覚えない。20Fのキングヘビリンゴは まほうじんが 無いので まねできない)
- **装備の 特殊能力**: 装備画面で えらんでいる 装備の 説明に「効果: 炎耐性30」「つよさ+1」などが 出る(`town.rs` の `equip_effects`。耐性の数字は `data.rs` の `resist`)

- **クエスト専用の品**(ワーネコホルターなど)は、そのクエストに必要な個数だけ落ちる。持っている間と、達成したあとは 落ちない

- **ボスの強さ**(`data.rs` の MONS。HP・ATK・DEFは 設計値だが、wikiの 攻略の文言と 数字に 合わせてある): 
  - 2Fリオン ATK40(「受けるダメージは(30-防御)程度」)。テツジンは 守備力が 異常に高い(DEF70)・光の全体攻撃が 約40ダメージ(HP80〜100ほしい)
  - カワウソーサラーは 物理が むだ(DEF30)。デビルプリンス(10F)は「防御力が 9階よりかなり高い」(DEF80)
  - 15F 以降は wiki の 攻撃力の 数字(15F 約180・16F 約200・17F 約210・19F 260)に 近づけ、18F HP1100・19F HP1165。守りは「つよくなれで 2ダメージ以上には 攻撃力200以上」(19F DEF約300)に 合わせた

- **ふつうの魔物の強さ**: ボスに くらべて 弱すぎたので、戦闘で ふつうの魔物の HP・ATK・DEF を 1.3倍(`sim.rs` の `NORMAL_BOOST`。ボスは そのまま。まほうじん・瘴気の倍率は その上に かさなる)。ものまねの 能力の もとの数値は 変えていない
- ドロップ率: ふつうの魔物は、表の確率を 全部足した 合計が **35%** を こえるとき、比例で 下げて 合計35%に そろえる(`data.rs` の `DROP_TOTAL_MAX`・`drop_permille`)。ボスは 表のまま。ドロップ判定は 今までどおり 1つずつ。複数匹の 戦闘の 加算と れいぞうこの 食べ物2倍は そのあとに かかる。botは 4日に1度 浅い階にも 行って 食材を 集める(食材は 浅い階の魔物しか 落とさない物がある)
- ただし 表の合計が **55%以上** の魔物(ランバーダック・サムライウルフ・アクマノサイコロ・チカラウシ・デタラメ・カワウソードマン・ワーネコ・キノコトカゲ・バクダンイモ・ヒブタ)は 確率を 下げず、1回だけ ふって「どれか1つだけ」落とす(`ONE_DROP_MIN_TOTAL`・`one_drop`)。表の合計が 100%を こえる魔物は 100%で 何か1つ落とす
- 武具屋の「かう」「うる」は、種類ごとの**タブ**(ぶき・たて・あたま・からだ・あし・ゆびわ。品数つき)に分かれる。**Q・E**かクリックで切りかえ(←→は個数のまま)。新入荷のあるタブには赤い!、開いたタブの分だけ見たことになる。最後に見たタブはおぼえている。確認用: `--screen armor_buy_<0-5>` / `armor_sell_<0-5>`
